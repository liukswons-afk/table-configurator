App para iPhone

  1. Sube la carpeta «lamas_cnc_iphone» (index.html, sw.js, manifest e iconos) a una web gratuita: Netlify Drop, GitHub Pages o Cloudflare Pages.
  2. Ábrela en Safari en el iPhone.
  3. Compartir → «Añadir a pantalla de inicio». Se abre a pantalla completa y funciona sin conexión.
  4. Los ZIP se guardan con Compartir → «Guardar en Archivos».
