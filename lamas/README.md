# Lamas CNC

Копія інструмента для проєктування рейкових (ламельних) стінових панелей і підготовки файлів для фрезерування на ЧПК: розкладка на листах 3000 × 2000 мм, DXF, G-code, STL.

## Запуск на комп'ютері
Відкрийте `index.html` у браузері (Chrome, Safari, Firefox).

## Встановлення на iPhone
1. Завантажте всю папку `lamas` (index.html, sw.js, manifest.webmanifest, іконки та папку vendor) на безкоштовний хостинг: Netlify Drop, GitHub Pages або Cloudflare Pages.
2. Відкрийте сайт у Safari на iPhone.
3. «Поділитися» → «На початковий екран». Програма відкриватиметься на весь екран і працюватиме без інтернету.
4. ZIP-файли зберігайте через «Поділитися» → «Зберегти у Файли».

**Завжди симулюйте G-code у своєму контролері або CAM перед першим різом:** перевірте нульову точку, діаметр фрези та перемички.
